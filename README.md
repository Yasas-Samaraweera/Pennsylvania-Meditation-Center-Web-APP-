# Pennsylvania Meditation Center

Welcome to the **Pennsylvania Meditation Center** web application – a calm and minimalistic platform designed to introduce visitors to the world of meditation, mindfulness, and spiritual practice.

## 🌿 Overview

This is a responsive and beautifully styled meditation website built using **TypeScript** and **Tailwind CSS**. The app provides information about the center, ongoing programs, meditation practices, and how to get involved.

## 🛠️ Built With

- **TypeScript** – for strong typing and scalable JavaScript development.
- **Tailwind CSS** – for fast and utility-first UI styling.
- **React** *(optional – include only if you used it)* – for building the interactive user interface.
- **Vite** or **Webpack** *(optional – mention the build tool if used)*.
